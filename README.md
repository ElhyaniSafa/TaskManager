**TaskManager – Application React**

TaskManager is a collaborative React project developed as part of the Agile Approach module. It is a simple task management application that allows users to display and manage tasks.

The application is built using React components, including Header, TaskCard, TaskList, and TaskForm. It uses React Hooks (useState), props, and map() to manage and display tasks.

This project is developed collaboratively using Git and GitHub, with each team member responsible for a specific component.
